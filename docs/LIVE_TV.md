# Live TV and recordings

Open **Live TV** in the sidebar to browse channels and programs or manage your recordings.
An administrator must add a source under **Settings → Live TV** first.

## Supported sources

| Source         | Setup                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------- |
| HDHomeRun      | Enter the device's HTTP address after scanning channels in HDHomeRun setup.                 |
| IPTV           | Enter an extended M3U playlist URL. No tuner emulator or xTeVe installation is required.    |
| Local tuner    | Install its driver, choose Windows BDA / Linux DVB, find the tuner, and select your region. |
| Linux DVB file | With v4l-utils, enter a channel file generated by dvbv5-scan.                               |
| NextPVR        | Enter the NextPVR server address and PIN after configuring its tuners and channels.         |
| Tvheadend      | Enter the Tvheadend server address after configuring its tuners and channels.               |

Hauppauge and other supported USB/PCIe tuners connect directly through Windows BDA or Linux DVB.
Koko scans terrestrial channels when you add a local tuner. Choose the delivery system and
frequency region for your antenna. Scanning can take several minutes. Koko includes the
required broadcast support; a separate TSDuck installation is not needed. NextPVR and
Tvheadend are optional alternatives.
Koko needs access to the source from the server, even when you use the web app on another device.
Encrypted or copy-protected channels are not supported.

Choose a source type to see its connection settings. HDHomeRun and NextPVR can be discovered
on the local network; Tvheadend can be discovered when its service announcements are enabled.
Discovery runs from the Koko server. Select a device's card to fill in its connection settings.
The selected card is highlighted; editing its address or tuner location clears the selection.
You can always enter the address manually if discovery
finds nothing, including when the source is on another subnet. For local tuners, choose a
discovered device or enter its driver name/path, then select a supported frequency region.
When no tuner is attached, **Find local tuners** reports that none were found.

Each source card shows its channel count and the M3U/XMLTV sizes from its last successful
import, when those files apply. Refresh the source to update these figures.
Source cards and provider sections start collapsed. Select a header to show its settings.

Use **Remove source** on a source card to remove its channels, guide, future recording
schedules, and series rules. Saved DVR recordings and their files are kept. Stop playback
and active recordings from the source before removing it.
Open **Edit connection settings** to change its saved values. Leave a saved NextPVR PIN
blank to keep it, or enter a replacement PIN.

### IPTV providers and FastChannels

For FastChannels, choose **IPTV (M3U)**, then select **FastChannels server** under
**IPTV connection**. Enter only the server address, such as `http://fastchannels.example:5523`.
Koko imports the default feed's native channels, available PrismCast channels, and their guide.
Enable and configure PrismCast in FastChannels to include its bridged channels.
Set **Simultaneous bridge streams** to the number of captures your PrismCast server allows;
this allowance is shared across its providers.

For an ordinary playlist, select **M3U playlist** and enter its URL. Enable
**Group channels by provider** when the playlist has provider prefixes in its channel IDs,
as FastChannels and E+TV do. After the import, each provider appears under the source card.
Expand a provider to change its name, show or hide it in the guide, or choose **Manage channels**
to edit only that provider's channel visibility and guide mappings.

In the guide, select the connection and then choose a provider or **All providers**.
Category filters, favorites, and recently played channels still apply within that selection.

FastChannels presets, HDHomeRun, NextPVR, and Tvheadend use their application icons.
Other connection types use standard symbols, and each provider has a default icon.
Use **Upload icon** on its Settings card
to replace it with a PNG, JPEG, WebP, or GIF image smaller than 5 MiB. For providers, the
**Provider icon** selector also offers icons from that provider's channels. A selected channel
icon updates automatically when the channel logo changes. Choose **Default provider icon**
or **Use default icon** to restore the bundled icon.

Under **Guide source groups**, choose **Add a source group**, enter a name, and select two
or more sources. They appear together as one lineup in the guide. For example, group a
regular FastChannels playlist with its separate PrismCast playlist. Each member keeps its
own guide settings and simultaneous stream limit. Editing or deleting a group keeps its
member sources, channels, favorites, and recordings.

Set **Simultaneous streams** to the number of tuners or streams your source permits.
Each live viewer and active recording uses one stream. Keeping the program you are watching
shares that viewer's stream until you change channel. A direct Linux DVB source uses one
adapter/frontend and allows one stream; add another source for a separate tuner.

For direct Linux tuners, install the appropriate firmware and allow Koko's service account to
access `/dev/dvb`. Generate a channel file with `dvbv5-scan` using the initial tuning file for
your region. Enter that output file's path in Koko, together with the adapter and frontend
numbers. If needed, specify the full path to `dvbv5-zap`.

## Program guide

The guide aligns channels along one scrollable timeline. Focus a program to preview its
artwork and description above the guide. Click or press **Enter** on a channel or program
to watch that channel live. Hold or right-click to open channel and recording options.
**Record program or series** opens a dialog with padding, series, and privacy settings.
Source and provider icons show channel counts; hover over an icon to see its name.
Providers are indented beneath their source. Open **Filters** to use categories, channel groups, favorites,
recently played channels, or search. Close the filters to leave more room for the guide.
Category filters and **NEW**, **LIVE**, **PREMIERE**, and **FINALE** labels depend on your guide's metadata.
With a guide cell focused, use **Page Up / Page Down** to move through a large lineup and
**Home / End** to reach its first or last channel. Up/down movement keeps the same schedule time.
Up and down keep the same time position as you move between channels. Left and right move
between programs. Completed half-hour columns disappear automatically; choose **Now** to
return from a future guide window to the current listings.
In the full video player, choose **Channel guide** to browse a compact Now/Next list while
the video continues playing. Search or filter by source, then select another channel to
switch. Close the channel guide to return the video to its full size.

Select the star next to a channel to add it to **Favorites**. **Recently played** shows the
channels you have watched, with the most recent first. Both lists belong to your account.

Choose the guide source when adding a TV source:

- **Automatic** uses HDHomeRun's guide, the NextPVR/Tvheadend guide, or broadcast guide
  reception for a local tuner.
- **Zap2It** finds OTA, cable, and satellite lineups by ZIP/postal code.
- **Over-the-air (DVB EIT / ATSC PSIP)** receives schedules from the broadcast itself.
- **XMLTV URL** downloads a guide from a URL you supply, including gzip-compressed feeds.

For NextPVR, **Automatic** keeps using NextPVR's listings. Selecting Zap2It or another guide
uses that guide's listings instead.

Choose **Program artwork** separately. **Automatic** tries your enabled TheMovieDB and TheTVDB
providers in their configured order, using the API keys saved in **Settings → Metadata providers**.
You can also select either provider individually or choose **Guide images only**. Artwork
matching leaves the selected guide's titles, descriptions, episode details, and schedules
in place. When a matching movie or series cannot be identified confidently, Koko keeps the
guide image.

You can also choose **Import XMLTV** on an existing source and select a local XMLTV file.
Importing a file selects that uploaded guide until you configure another guide source.
Upload a newer file when its listings expire.

M3U playlists and XMLTV guides have no fixed import size or entry-count limit. Large feeds
need enough free temporary disk space and memory to process their channels and listings.
Gzip-compressed XMLTV files are supported for both URLs and uploads.

Koko automatically removes expired listings, keeping up to 24 hours of guide history and
21 days of upcoming programs. This also applies when a source is offline or disabled.
Saved recordings and their program details are retained until you delete the recording.

HDHomeRun currently supplies two days of guide data without a separate guide account, or
fourteen days with its DVR guide subscription. Availability depends on the device and region.
See the [HDHomeRun guide documentation](https://github.com/Silicondust/documentation/wiki/XMLTV-Guide-Data).

For Zap2It, select **USA** or **CAN**, enter your ZIP/postal code, and choose **Find providers**.
Select your provider and guide horizon, then save the source. Listings update initially and
daily afterward. Set **Refresh interval (hours)** to change this; zero uses the provider default.
Zap2It's public listings service may change or be unavailable; use XMLTV or broadcast guides
if it cannot supply your listings.

For broadcast guide reception, local tuner sources use their
scanned channels. For a network tuner, supply one unfiltered multiplex URL per broadcast
frequency. An HDHomeRun example is `http://192.168.1.20:5004/auto/ch473000000`.
Use the physical RF frequency or channel number, rather than a virtual channel URL.
See [HDHomeRun HTTP streaming](https://info.hdhomerun.com/info/http_api).

Broadcast scans use an available tuner and wait when a recording is due or running.
Guide duration and descriptions depend on the broadcaster. Some stations supply only the
current and next program; others supply several days. Broadcast schedules may lack episode
numbers, images, or new-episode flags.

Open **Channel visibility and guide mapping** on the relevant source card. Search or page
through that source's channels, disable unwanted channels, or select the correct
guide station when its listings are missing or incorrect. You can watch channels and schedule
recordings by time even without guide data.

## Record programs

### Pause and rewind live TV

Watching a channel automatically starts a temporary recording. Playback uses this buffer, so
you can pause, rewind within the available buffer, and change playback quality. You can only rewind
as far as the point when you started watching. Choose **Skip to end**, beside the forward
button, to return to the newest available point. If playback stalls, Koko tries to reconnect
automatically. You can still choose **Skip to end**
or **Retry playback** if it cannot recover.

Closing the full player keeps the channel playing as the hero's artwork. Choose **Expand player** to
return to the full player, or choose **Stop playback** to stop it. Changing channels or leaving
Live TV stops that channel's temporary recording and removes its buffer.

Choose the recording icon to the left of skip back in the full player's playback bar, then **Shared recording** or
**Private recording**, to save the available buffered portion of the current program and
continue recording until its scheduled end. If listings are missing, it
records for one hour from when you choose to keep it. Kept recordings continue when you
change channel or leave Live TV; watching another channel then requires another available
stream. Use **Stop recording** under **Recordings** to end one early.

Choose **Shared recording** to make it available to all accounts, or **Private recording** to limit access
to your account. Accounts without recording permission can use temporary playback buffers
but cannot keep them. Buffers use the configured DVR save folder and need free disk space.

### Schedule recordings

Open a program in the guide and choose **Record program** or **Record series**. You can add
padding before and after the scheduled time. **New episodes only** requires the guide to
explicitly identify new episodes; programs without that information are not added by that rule.
Series rules apply to the selected channel and program title.

Use **Recordings → Schedule by time** when a channel has no guide or you want a custom time
range. The times shown and entered in the browser use your local timezone.

Recordings and series are shared with all accounts by default. Select **Private (only my account)**
when scheduling to keep a recording or series private. The account that schedules it manages
its timers and saved video. **Stop series** cancels its future
timers and keeps saved recordings. **Stop recording** retains the portion already captured.
Choose **Delete recording** to remove a stopped capture and its saved video.

Keep the server running, with enough free disk space, for scheduled recordings. Recordings
are saved under `live-tv/recordings` in the server's data directory by default. Administrators
can change **DVR storage and recording permissions → DVR save folder** to an absolute path
on the server. New captures use that folder; existing recordings keep their locations.
The server account needs permission to create, write, and delete files there.

Administrators can enable or disable **Allow recording** for each account. Disabling it
cancels that account's future timers and disables its series rules; a running recording continues.
Accounts can still watch shared recordings when their recording permission is disabled.

If the server restarts
during a recording, capture resumes when possible and the recording reports a possible gap.

## Troubleshooting

- **All tuners are busy:** stop another viewer or recording, or check the source's stream limit.
- **Guide missing:** check source status, reception, the XMLTV address/file, and channel mapping.
- **No broadcast schedule received:** verify that the stream is unfiltered and includes guide
  tables. Some tuner and IPTV streams contain only audio and video.
- **Playback fails:** check reception, source credentials, and the FFmpeg path in Settings.
- **Playback stutters:** try a lower quality in the player, and check network speed and reception.
- **Recording conflicts:** cancel an overlapping timer or increase the stream allowance only
  if the source has additional available tuners or permits more IPTV streams.
- **Recording fails:** check source availability, filesystem permissions, and free disk space.
